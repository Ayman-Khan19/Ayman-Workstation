# Ayman Workstation

A simple Linux bootstrap repository for Cloud/DevOps.

## Included Software

- Git
- Python
- Node.js
- VS Code
- Google Chrome
- Docker
- Docker Compose
- Kubernetes (kubectl)
- Minikube
- AWS CLI
- Terraform
- GitHub CLI
- curl
- wget
- jq
- htop
- tree
- zip
- unzip

## Installation

Clone the repository

```bash
git clone git@github.com:Ayman-Khan19/Ayman-Workstation.git
```

Go into it

```bash
cd Ayman-Workstation
```

Run

```bash
chmod +x install.sh
./install.sh
```

## Goal

Create a fresh Ubuntu installation ready for Cloud Engineering and DevOps.
